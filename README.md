## 1. 先看结论
> 结论

**要掌握强弱电。**钻石切割机不是纯机械。主轴、水泵、升降和行走是强电；急停、限位、触摸屏、变频器参数和报警是弱电。只会装导轨、不会看电气图的班组，可以把机器拼起来，但不能安全通电，也过不了出口验货。

- **机械装配工：**必须懂安全用电，认识接地、急停、相序和防护罩联锁，禁止私自改线、短接保护。不要求会画PLC程序。
- **电柜装配和整机接线：**强电和弱电都要会。国内至少按电工安全操作和 GB/T 5226.1（机械电气安全，对应国际标准 IEC 60204-1）来做。出口欧盟基本要对齐 EN 60204-1；出口美国还要对 NFPA 79，不能拿国内习惯柜直接发走。
- **调试：**在接线之上，还要会改电压抽头、核对 50 Hz / 60 Hz、限制锯片线速度、把界面和报警改成英文，并备份参数。
- **跟单：**不必拿电工证，但必须看得懂铭牌上的电压、频率、功率、电流，以及第8节里的合同用语。下单前不确认电源，是出口索赔里最贵的一种低级错误。

不需要每个人都达到注册电气工程师水平。需要的是：**该持证的人持证接线，该分开的回路分开接，该问客户的电源先问清楚。**

## 2. 本文说的是哪一种机器
中文“钻石切割机”在车间和外贸里经常混用。出口文件必须写成明确的英文，否则清关归类和说明书会对不上。

| 中文常用叫法 | 建议英文 | 和电气的关系 |
| --- | --- | --- |
| 红外线桥切机、桥式切石机 | Bridge saw / Infrared bridge cutting machine | 主轴电机 + 横梁行走 + 升降，常见 PLC 或数控 |
| 龙门大切、块石圆盘锯 | Block cutter / Gantry saw | 大功率主电机，多刀时还有多路进给 |
| 金刚石绳锯机 | Diamond wire saw machine | 主驱、行走、张紧、导向轮；断绳风险高 |
| 多线锯、多绳锯 | Multi-wire saw | 功率大，张力、收放线、冷却全部要联锁 |
| 工地切石机、砌块切割机 | Masonry and stone cutting-off machine | 功率较小，但水多，触电风险不低 |
| 手持切割机 | Hand-held cut-off machine | 另有手持工具安全标准，不要和固定式桥切写成同一种机器 |

> 不要和晶圆划片机混为一谈

半导体用的金刚石划片机英文是 dicing saw，车间洁净要求、标准体系和海关编码都不同（石材锯切常见归入税号 8464.10 项下的锯切机器；划片机不是这一类）。客户说 diamond cutting machine 时，先问清切的是石头、混凝土、陶瓷，还是晶圆。本文默认前一类。

税号只作预判。中国出口常见把石材锯切设备归到 8464.10（sawing machines）。印度等国税则里还有更细的花岗岩切割设备编码。最终以报关行按型号、工作原理和材质做的归类为准，不要把手册上的号码直接印上发票。

## 3. 组装到底要不要掌握强弱电

### 3.1 在这台机器上，强电和弱电指什么
**强电**是会伤人、也能烧电机的那一部分：进线电源、主断路器、接触器、热继电器、变频器主回路、主轴电机、水泵、液压泵、行走电机，以及保护接地。

**弱电**是用来指挥强电的那一部分：控制变压器或开关电源后面的直流 24 V、PLC 输入输出、触摸屏、接近开关、编码器、限位、急停回路、安全继电器、张力传感器、水位或流量开关、通讯线。

两者接错的后果不一样。强电接错会打火、反转、烧变频器和锯片超速。弱电接错会表现为“能转但保护是假的”：急停无效、限位无效、护罩打开还在切、报警全是中文看不懂。出口客户更恨第二种，因为机器看起来是好的。

### 3.2 按岗位分，不要全员学成电工
| 岗位 | 强电要到什么程度 | 弱电要到什么程度 | 资格 |
| --- | --- | --- | --- |
| 机械装配 | 会看总开关、接地桩、电缆拖链不要夹线；通电时不站在湿手湿地上操作 | 认识急停、限位、护罩开关，发现被短接要上报 | 安全培训。不单独接电柜 |
| 电气装配 | 看懂主回路，压接、线号、接地、相序、进出线分开；会用万用表 | 按图纸接 24 V、I/O、屏蔽层；能说出每根安全线是干什么的 | 电工作业资格。出口机按目的国标准接线 |
| 调试 | 核对电压抽头、电机转向、变频器额定参数、最高频率 | 会看报警、原点、联锁；能把界面改成英文并备份 | 同上，另加原厂或自制调试规程 |
| 外贸跟单 | 能翻译铭牌：电压、频率、功率、电流、相数 | 知道 PLC、HMI、inverter、E-stop 在合同里不能乱写 | 不代替电工承诺“我们有 CE” |

### 3.3 职业上本来就要求安全用电
石材切割、机械切割这类工种的国家职业标准里，安全用电、切割安全操作、防护用品都是基础知识，不是出口了才额外加的。水、金属粉和旋转刀具在一起，漏电和飞片是两类主要致命风险。组装阶段就把保护装假，等于把风险交给国外的操作工。

## 4. 这台机器的电气是怎么分成强电和弱电的
从电源到锯片，典型路径如下。不同机型会少几路，但出口图纸最好按这个逻辑画，英文原理图和线号一致。

1. 客户配电：三相电源，有的带中性线，一定要有保护接地。机器自带总隔离开关（主开关），能锁住，方便检修挂牌。
2. 主回路：断路器 → 接触器或变频器 → 主轴电机。支路再去水泵、液压站、升降、横梁、工作台。
3. 控制电源：控制变压器或开关电源，输出交流控制电压或直流 24 V。不要直接用相线给按钮和传感器。
4. 控制器：PLC、数控或专用控制器，加触摸屏。它发指令给接触器和变频器，自己不拿主电机的大电流。
5. 安全回路：急停、护罩、限位、断水、过载、断绳（绳锯）。这一路要求“断了就停”，不能只在屏幕上弹一个窗口。

> 组装时先建立这个概念

主开关拉开以后，电柜里仍可能有外供的灯、插座或 UPS。这类“主开关断开后仍然带电”的线，出口标准里常用橙色标出。柜门内侧要有警告，不能让调试员以为拉了总闸就绝对没电。

## 5. 强电：组装必须会的

### 5.1 先看铭牌，再接线
接线前核对四件事，缺一就停：

- 电压 rated voltage，例如 380 V、400 V、415 V、480 V。三相还是单相。
- 频率 rated frequency，50 Hz 还是 60 Hz。只看电压不看频率，锯片线速度可能超限。
- 满载电流 full-load current 和总功率 total power / rated power。用来核对客户空开和进线截面，不是用来在现场随便加粗保险丝。
- 防护等级 IP。切石现场有水，电柜、电机、按钮盒、格兰头要和铭牌一致。格兰没拧紧，海运或第一周溅水就会进柜。

### 5.2 主回路里这些词必须分得清
| 器件 | 英文 | 组装注意 |
| --- | --- | --- |
| 隔离开关 / 主开关 | Supply disconnecting device / Main switch | 能切断全部电源，有明显分合位置，检修可上锁 |
| 断路器 | Circuit breaker | 短路和过载保护，整定值按图纸，不要换大一号“不容易跳” |
| 接触器 | Contactor | 线圈电压看清是 24 V、110 V 还是 220 V，线圈接错会吸合不了或烧线圈 |
| 热继电器 | Thermal overload relay | 整定到电机额定电流，复位方式不要设成自动复位后自行再启动 |
| 变频器 | VFD / Inverter / Variable frequency drive | 进线接 R/S/T 或 L1/L2/L3，出线接 U/V/W。输出侧不要接普通电容补偿，也不要随便加不匹配的漏电开关 |
| 软启动器 | Soft starter | 大功率主电机用。旁路接触器的时序按厂家图，不要自己改 |
| 电抗器 / 滤波器 | Reactor / EMC filter | 出口机常有。滤波器金属壳必须大面积接地，不是只接一根细地线 |
| 制动电阻 | Braking resistor | 升降、快速停止会用到。电阻发热，不能贴电缆和电柜隔热棉 |

### 5.3 接地是强电里最不能省的一根线
- 保护接地线必须是黄绿双色，整机连续，从进线接地桩到电机外壳、电柜门、导轨和金属水管该接的都要接上。
- 黄绿线不能拿来当相线，也不能只靠插头弹片接触，要压接或螺栓锁紧。
- 切石是潮湿场所。客户侧建议使用剩余电流动作保护（漏电保护）。湿区人体保护常见动作电流不大于 30 mA。变频器对地泄漏电流大，漏电开关型号和安装位置要按变频器手册选，装在输出侧常常误跳或失去保护意义。
- 等电位：机器、水管、基础钢筋如果图纸要求联结，不要省。有的欧洲说明书会直接写 equipotential bonding。

### 5.4 绝缘和通电的顺序
电子板、变频器和 PLC 不能直接用兆欧表高压去“摇”。正确顺序是：先按图纸把电子装置甩开或按厂家规定短接，再测动力电缆和电机绝缘，然后恢复接线，最后由电工送电。先空载点动看转向，再带水，最后才允许下刀。没有冷却水就切，会烧锯片、烧绳锯橡胶或塑料隔套，也会扬起石粉。

> 禁止

为了赶验货，用铜丝代替保险丝、短接热继电器、短接急停和门锁后“先出货再说”。这类跳线如果留在机器里，属于把安全装置交出去失效。出厂记录里要有一项：所有临时短接线已拆除。

## 6. 弱电：组装必须会的

### 6.1 控制电源和线色
出口电柜内部常用习惯（以 EN 60204-1 的推荐色为主，具体以该机图纸的线色表为准）：

| 回路 | 常见线色 | 说明 |
| --- | --- | --- |
| 保护接地 PE | 黄绿 | 唯一强制双色，不能挪作他用 |
| 中性线 N | 浅蓝色 | 没有中性线的机器不要自己拉一根“零线”去接地 |
| 动力相线（柜内） | 黑色为主 | 靠线号 L1/L2/L3 区分，不靠颜色猜相序 |
| 交流控制 | 红色 | 例如 110 V 或 230 V 线圈回路 |
| 直流控制 | 蓝色 | 常见 DC 24 V。正极负极仍要有线号，不能只看颜色 |
| 主开关断开后仍带电 | 橙色 | 外供照明、插座等 |

> 国内习惯和出口冲突最大的地方

很多国内电工把三相做成黄、绿、红。绿色单独做相线，到了欧洲或北美会被当成地线。出口柜不要用单绿色、单黄色做相线。外部电源进线若按欧洲安装电缆，常见是 L1 棕、L2 黑、L3 灰、N 蓝、PE 黄绿。机器进线端子必须有清晰的 L1/L2/L3/N/PE 标记，并在说明书里给一张线色对照，避免国外电工按颜色误接。

### 6.2 这些弱电部件决定“保护是真是假”
| 部件 | 英文 | 组装要求 |
| --- | --- | --- |
| 急停 | Emergency stop / E-stop | 红蘑菇头、黄底，按下自锁。复位后主轴不能自己转起来，必须再按启动 |
| 安全继电器或安全模块 | Safety relay | 出口机的急停、护罩不要只用普通中间继电器凑。是否达到某个性能等级，由设计计算，装配工不要擅自更换型号 |
| 限位开关 | Limit switch | 升降上极限、行走两端。软限位之外还要有硬限位，硬限位动作时驱动必须停 |
| 接近开关 | Proximity switch | NPN/PNP、常开常闭要和 PLC 输入一致。屏蔽线按图单端接地，两端都接会引入干扰 |
| 编码器 | Encoder | 插头针脚不要焊反。电缆不要和电机动力线捆在同一扎里 |
| 触摸屏 / 人机界面 | HMI / Touch screen | 出口机默认语言用英文。中文界面可以保留为第二语言，但不能只有中文 |
| 可编程控制器 | PLC | 程序版本、校验和、备份日期写进出厂记录。U 盘文件名用英文和序列号 |
| 伺服 / 步进 | Servo drive / Stepper drive | 方向、原点、限位逻辑和机械零点一致后再锁参数 |

### 6.3 和切割工艺绑在一起的联锁
- **冷却：**coolant / cooling water。有流量开关或压力开关的，断水应停止进给或报警，而不是只靠操作工眼看。
- **张紧：**wire tension。绳锯、多线锯张力不够就高速转，会打滑、跳齿、断绳。张力单位在屏幕上写清是 N、kN 还是 bar，不要只写一个内部数字。
- **护罩：**guard / blade guard。打开护罩时主轴不能启动；切割中打开护罩，主轴应停止。
- **相序和转向：**主轴、泵、行走第一次上电只用点动。锯片上的旋转箭头和主轴实际转向一致。螺母旋向要能在旋转中越转越紧，这项以主轴图纸为准，不能凭感觉换左旋右旋。

### 6.4 屏蔽和布线
动力线和编码器、通讯、模拟量分开走线。必须交叉时尽量垂直交叉，不要长距离平行捆扎。屏蔽层按图处理：电机屏蔽电缆在变频器和电机两端用金属格兰做 360 度环接，是出口电磁兼容里最常被省掉、也最常被验出来的一项。线槽盖盖好，线号套管和图纸一致，备用芯线接到备用端子或按图绝缘，不要剪掉线号。

## 7. 组装顺序和通电前检查
下列顺序适用于桥切、绳锯一类需要地基的设备。工地小锯可以跳过地基，但水电和防护不能跳。

1. **开箱。**对照装箱单 packing list，拍照记录磕碰。电柜、主轴、导轨、说明书、电气图单独清点。缺件在通电前处理。
2. **地基和就位。**按基础图 foundation drawing 做，预留排水。水平度按该机图纸，不要套用别的机型的 0.1 mm/m 之类经验数。吊点用图纸指定的，禁止吊电柜和护罩当吊耳。
3. **机械。**导轨接头、横梁、升降丝杆或油缸、绳轮或法兰。手动盘车，全程无卡滞，再装限位撞块。
4. **刀具。**锯片法兰用原配，不能用普通垫圈代替。绳锯接头按绳的厂商工艺压接，预扭和张紧力用厂商数据。刀具最大线速度写在刀具上，机器最高转速不许超过它。
5. **水、液压、气。**先做泄漏检查。液压接头拆开前要泄压。油的牌号写进说明书，随机油品如果走空运，提前确认能不能当普通货物发。
6. **接线。**按英文线号图，一人接、一人复看。重点看：电源端子、电机转向线、PE、急停串在安全回路里而不是只接了指示灯、限位没有被线槽盖压住。
7. **未送主电的测量。**保护接地连续性；在电子装置被保护的前提下做绝缘检查；确认控制变压器抽头位置和目的国电压一致。
8. **送电。**先控制电源，看触摸屏和风扇。再点动各轴。确认急停、限位、护罩、断水。最后装刀具，开冷却，低速试切。
9. **备份。**变频器参数、PLC、触摸屏各存一份，文件名带型号和出厂编号。出厂检验单由装配和调试签字。

> 试切时的工艺限度，不要在组装现场破例

冷却水中断马上停。进给和下刀过快会切弯、闷车、崩边。绳锯操作位置不要放在绳的切线方向上；现场应有危险区域标识，无关人员不得进入。具体安全距离以该机风险评估和说明书为准，不要用“离远一点”代替挡板。

## 9. 电压、频率和线色
这是出口组装里最要先问客户的一页。下表是常见情况，**不是每个工厂都这样**。沙特和阿联酋都在中东，频率却常常不同。日本东部和西部频率也不同。正确做法是向客户要配电柜照片或电费单，并让对方书面确认。

| 地区 | 工业电源常见值 | 频率 | 组装时多问一句 |
| --- | --- | --- | --- |
| 中国 | 三相 380 V | 50 Hz | 出厂试验电源。出口机不要用这组参数当默认铭牌 |
| 欧盟、英国 | 三相 400 V，控制侧常有 230 V 或只用 24 V 直流 | 50 Hz | 旧厂偶尔仍说 380 V，要确认波动范围 |
| 澳大利亚、新西兰 | 400 V 或 415 V | 50 Hz |  |
| 印度及部分东南亚 | 415 V 或 380 V | 50 Hz | 电压偏低、波动大的工厂要问清最低电压 |
| 阿联酋等 | 400/230 V 常见 | 多为 50 Hz | 不要和沙特当成同一个电源 |
| 沙特 | 380/220 V 很常见 | 多为 60 Hz | 电压像中国，频率不是。只改电压不改频率会超速 |
| 韩国、菲律宾、台湾 | 工业三相常见 380 V 或 220 V | 60 Hz | 同上 |
| 日本 | 三相 200 V 居多 | 东部 50 Hz，西部 60 Hz | 不要发 380 V 电机过去硬接 |
| 美国 | 工业多为 480 V，小机器有 230 V 或 240 V | 60 Hz | 还要问有没有中性线、谁做盘柜认证、要不要 SCCR |
| 加拿大 | 480 V 或 575/600 V，看省份 | 60 Hz | 600 V 系统不能当 480 V 发 |
| 巴西、墨西哥 | 州与州差别大，可见 220、380、440、480 V | 60 Hz | 必须按项目确认，不能按“南美”一概而论 |

> 50 Hz 和 60 Hz 为什么是安全问题，不只是快一点

普通异步电机转速大约和频率成正比。按 50 Hz 设计的主轴若直接接到 60 Hz，空载转速大约升高两成。锯片线速度等于圆周率 × 直径 × 转速。线速度超过锯片标定值，有爆片风险。反过来，60 Hz 电机长期跑在 50 Hz，出力下降，自带风扇风量变小，容易过热。

用变频器的机器也不能只在参数里把上限频率一改了事。要同时核对电机额定频率、最高频率、机械减速比，以及锯片允许的最大线速度，把主轴转速限制锁死。水泵和液压泵的流量、压力也会随转速变，冷却和夹紧力要重新试。

控制变压器有抽头的，出厂前把抽头打到合同电压，并在抽头旁贴英文标签，例如 Connected for 480 V 60 Hz。双电压电机的星三角接法用图贴在接线盒盖内侧。铭牌、抽头、实际接线三者不一致，客户有权拒收。

## 10. 认证、铭牌和随机文件
> 先说清楚边界

标志可以买贴纸，技术文件买不来。没有风险评估、电气图、测试记录和符合性声明，就在机身上贴 CE，属于误用标志。被市场监督或客户验出来，机器会被要求下架或退运，严重的会牵连同一买家的下一批货。

### 10.1 主要市场在要什么
| 市场 | 常见要求 | 和组装的关系 |
| --- | --- | --- |
| 欧盟 | 2026年出货仍主要按机械指令 2006/42/EC 做 CE，同时涉及低电压、电磁兼容等。新的机械法规 (EU) 2023/1230 预计自 2027年1月20日起适用。电气常用 EN 60204-1，风险方法用 EN ISO 12100。工地切石机看 EN 12418，固定式金刚石绳锯看 EN 15163 这一类 C 类标准（以该机范围是否落入标准为准） | 护罩、急停、电气柜、英文说明书、符合性声明、技术文件存档。日期和适用指令以当时官方文本为准，合同里写明按哪一版做 |
| 英国 | UKCA 与 CE 的接受范围政府调整过。下单时确认这一类机械当时认 CE 还是必须 UKCA，两套文件不要互相抄了不改名称 | 铭牌上的标志和声明文件一致 |
| 美国 | 没有和 CE 一一对应的全国强制“机器标志”。现场安全看 OSHA，工厂电气安装看 NEC，工业机械电气常用 NFPA 79。买家经常额外要求控制盘有 UL 508A 或 ETL 等 NRTL 认证 | 没做盘柜认证就不要在报价单写 UL。线色、断路器分断能力、SCCR 经常在验货时被问 |
| 欧亚经济联盟 | EAC | 俄文资料和证书主体要一致 |
| 沙特等 | SASO / SABER 一类符合性程序，看产品清单 | 先问清清关代理要哪份证书，再安排测试，不要货到港再补 |

标准号会换版。采购合同时写“符合合同附录列出的、发货时有效的版本”，并让做认证的人按机器实际结构选 C 类标准，不要桥切机拿手持工具标准去套。

### 10.2 随机文件最少这些
- 英文使用说明书：用途、禁止的用途、噪声和粉尘提示、安装、地基、吊装、电气连接、操作、润滑、易损件更换、故障表。
- 英文电气原理图和接线表，图号、版本、日期和实机一致。
- 地基图、外形图、水电接口图（功率、电流、推荐上游断路器仅作参考值，并写明由客户电工按当地规范最终选型）。
- 备件清单，带厂家件号。
- 出厂检验记录：绝缘和接地的处理方式、急停测试、转向、空载运行、试切与否。
- 欧盟：EU 符合性声明，列型号、编号规则、适用法规、协调标准、签字人和职位。技术文件在制造商处存档，保存年限按当时法规（机械指令体系下通常强调长期可追溯，按认证顾问给的年限执行）。
- 质量合格证，编号与铭牌相同。

说明书要写**不该怎么用**：例如不要干切说明书禁止的材料、不要拆护罩、不要超过最大锯片直径、不要站在绳锯切线方向、不要让未培训人员操作。这些句子同时是风险说明，翻译时不要删掉“看起来吓客户”的段落。

## 11. 安全红线

### 11.1 电
- 带电部分只有电工在隔离、验电之后才能碰。柜门打开后，带电体应有防护，避免手一伸进去就碰到铜排。
- 急停至少要停主轴和进给。按下保持，正方向断开触点。复位不等于启动。
- 湿手、湿鞋、站在积水里调试，视为违章，不因为“只是点一下”例外。
- 临时线过通道要架高或加盖，不能让石材叉车碾过。
- 更换锯片、压接绳锯、进电柜，执行上锁挂牌：断开主开关，锁上，挂牌，验电。

### 11.2 机械和粉尘
- 锯片有裂纹、缺块、孔径不对、法兰接触面有脏物，不上机。
- 防护罩盖住非切割区域。罩壳强度不够时不要自行改薄。
- 绳锯：接头压接不实、弯折半径过小、新旧绳混用不当，都会断绳或掉珠。断绳后不要强行拉拽。
- 湿切是默认工艺。石粉里的结晶硅长期吸入会伤害肺部，干式工序必须有吸尘，并写进说明书。操作工要有眼镜、听力防护、安全鞋；吊装时还有安全帽。
- 噪声大的桥切和绳锯，不要靠“习惯了就好”。说明书里保留噪声说明，出口测试若合同要求声功率级，要在发货前测，不要到了客户实验室才第一次知道。

### 11.3 调试现场
- 第一次旋转无刀具或用厂家允许的方式点动，确认转向后再装刀。
- 冷却正常之前，进给保持关闭。
- 试切样件固定牢。石材翻倒是组装现场的常见事故，和电没有关系，但一样会出人命。
- 绳锯运行时，操作者在防护挡板后，不在绳的延长线上。

## 12. 包装、运输和合同里要写死的技术条件

### 12.1 包装
- 实木箱按 ISPM 15 做处理，箱上有规范的 IPPC 标记。标记和证书与箱数相符。胶合板等是否免处理，按包装材料实际种类申报，不要实木盖一个“免熏蒸”章。
- 电柜内放干燥剂，缝隙封好。海运冷凝水会腐蚀端子，到港第一周的故障很多其实是受潮。
- 主轴、导轨防锈。说明书写明开机前要清掉哪一层防锈油，否则客户会带着油空转，然后投诉发热。
- 锯片、绳锯单独固定，不能压在电柜上。易损件清单和实物件数一致。
- 箱面：吊点、重心、向上、怕潮、怕撞。多箱时写 1 of 3 这种编号，和装箱单相同。
- 液压油、油漆、电池、干燥剂里的危险成分，空运前让货代看 MSDS。能不随机发的油，就改成客户当地采购，说明书写牌号和粘度等级。

### 12.2 合同技术附件建议原文包含的项目
商务合同可以很短，但技术页必须有下面这些，否则“机器是好的、电源不对”会变成卖方责任：

1. 安装国家、城市、室内还是露天。
2. 电源：相数、电压、频率、是否有中性线、接地型式如果客户知道就写上。
3. 客户提供：上游开关的位置、电缆做到机器主开关、水源水压、地基由谁施工。
4. 控制电压，通常写 DC 24 V，避免和现场 110 V 按钮习惯冲突时没人负责。
5. 语言：触摸屏和纸质说明书的语言。只有英文，还是英文加西语、阿语、俄语。
6. 认证范围：CE、UKCA、EAC、SASO，或“无第三方认证、仅出厂检验”。写了 UL 就必须真的做盘柜。
7. 随机刀具：直径、孔、片厚、最大线速度。不确定就写“不含锯片，买方按说明书允许的规格自备”。
8. 调试：远程还是派人，天数，签证和安全培训由谁办。绳锯和大型桥切很多纠纷出在“货到了没有人会水准和调张力”。
9. 质保排除：错误电源、短接保护、无水切割、使用超规格锯片、私自改 PLC。
10. 备件包：法兰、密封、开关、皮带或滤芯的数量。

## 14. 常见退货和索赔原因
| 现象 | 多半是组装或出货没做的事 | 怎么避免 |
| --- | --- | --- |
| 一通电就跳闸或变频器过压 | 380 V 机器接到 480 V，或抽头没改 | 合同确认单 + 出厂抽头标签 |
| 锯片声音异常、法兰发热、客户说危险 | 50 Hz 电机上了 60 Hz，线速度超限 | 频率写进铭牌，变频器上限锁死 |
| 转向反了，石材崩边 | 相序没点动就切 | 说明书要求先 jog；检验单记录转向 |
| 电工拒绝接线 | 黄绿红相线，没有英文图纸，PE 不清楚 | 按出口线色和线号做 |
| 验货说急停是假的 | 急停只断了 PLC 输入，接触器能用别的通路吸合；或复位后自启动 | 按安全回路测，不要只在屏幕上看报警 |
| CE 被认定无效 | 只有贴纸，没有声明、没有标准清单、说明书缺安全章节 | 没有文件就不贴标志 |
| 美国客户拒收电柜 | 报价写了 UL，柜子是普通国内柜 | 做不到的认证不要写进 PI |
| 到港木箱被退 | 实木无 IPPC，或标记模糊 | 装完箱拍照标记，随附证明 |
| 调试员打开柜发现受潮打火 | 海运无干燥剂、格兰松、柜顶进水 | 包装检查表 |
| 界面无法培训 | 只有中文，报警是内部代码没有英文解释 | 报警表进说明书，中英对照 |
| 断绳、飞片 | 张力、法兰、护罩、超径锯片 | 刀具规格写进合同，护罩联锁出厂实测 |
| 质保争议 | 客户自行改了 PLC 或短接限位 | 合同排除条款，程序加密或版本号，远程只读备份 |

## 附：车间可以贴出来的十条
1. 没有铭牌电压和频率，不接线。
2. 黄绿线只做保护接地。
3. 急停、护罩、限位不许短接出厂。
4. 先点动看转向，再装刀；先有水，再下刀。
5. 锯片线速度不许超过刀具标注。
6. 电柜按英文图纸走线号，程序用英文备份。
7. 主开关要能锁，检修先验电。
8. 吊装只吊标记的吊点。
9. 实木箱没有 IPPC 标记不出门。
10. 客户没书面确认电源，生产计划里就还是“未冻结电气”。
